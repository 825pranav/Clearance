# Figma

## What it is
Figma is the shared design tool. It holds product mockups, the design system component library and prototypes used in user research.

## Owner
Kai Walker (IT) administers the Figma organisation and its licences.

## Access levels
- **Read**: view and comment on design files. Anyone who needs to inspect specs, measurements or exported assets only needs read.
- **Write**: create and edit design files and publish changes to team libraries. Designers get write by default.
- **Admin**: manage teams, licences, shared libraries and organisation settings. Admin always counts as high risk because it controls who can see every design file.

## Risk tier
Low.

## Justification expected
A justification is optional for read and write. Admin requests need a full reason, such as a team restructure that needs library ownership moved.
