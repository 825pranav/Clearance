# Least Privilege

## The principle
Ask for the lowest access level that lets you do the work, and only for the systems you need. Every extra permission is something that can be misused, phished or mistyped.

## Choosing a level
- If you only need to view dashboards, logs or records, ask for read.
- Ask for write when you need to create or change things as part of your job.
- Admin is for people who manage the system itself. Do not ask for admin just in case you might need it later; ask again when the need is real.

## Why it matters
Lower access means fewer approvals, faster turnaround and a smaller blast radius if an account is compromised. Auditors also check that access matches job duties.

## Baseline access
Each role comes with baseline access to the tools that role uses every day. You never need to request access your role already includes.
